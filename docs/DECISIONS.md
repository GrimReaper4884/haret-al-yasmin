# Decisions

Dated log of every design deviation, TUNE change and process choice. Newest at the bottom. One line per
decision where possible; link the doc or commit that carries the detail.

| ID | Date | Decision | Why / detail |
|---|---|---|---|
| D-001 | 2026-10-17 | **Keep this codebase and design** (branch `feat/vertical-slice`: the lane lobby, the Damascus-lane cast, odds 75.5 / 20 / 4 / 0.5 %, pity 50 / 400). From the cloud research branch `origin/claude/gifted-franklin-4fv2sn` only the process files were adopted (`CLAUDE.md`, `docs/BUILD_PLAN.md`, `docs/TOOLS.md`, this file) plus `reports/` as background. Its Config modules, `wally.toml`, `default.project.json`, Main scripts and "Jasmine Quarter / the Wilt" design were **not** imported. | Owner's choice (chat, 2026-10-17). The kit forked from the initial commit and described a different game; merging it would have overwritten GAME_DESIGN.md, both Main scripts and the Rojo project. |
| D-002 | 2026-10-17 | Tool names follow `docs/TOOLS.md`, not the research kit: the Blender server is the official Blender Lab one (`get_objects_summary`, `get_blendfile_summary_path_info`, `get_screenshot_of_area_as_image`, `render_thumbnail_to_path`…); `get_scene_info`, `get_addon_status`, `look`, `search_assets`, `import_asset`, `generate_3d` do not exist. Studio also has `generate_texture` and `segment_mesh`. The place is "Haret Al-Yasmin (TEST)". | Observed with `claude mcp list` and the tool schemas (P0-01). |
| D-003 | 2026-10-17 | Tests run with **Lune** (`lune run tests/run`, specs in `tests/*.spec.luau`), not Jest-Lua. Wally stays installed with an empty `wally.toml`; no `Packages/` until a dependency is actually needed. | The runner and 147 specs already exist; Jest-Lua needs a Studio FFlag and would duplicate them. |
| D-004 | 2026-10-17 | Characters and props come from **Meshy → GLB → Studio importer → `.rbxm` in `assets/production`** (Rojo-synced) with signature clips baked by `tools/anim/bake.py`. Blender is for headless previews and inspection. An Open Cloud uploader (`tools/upload_asset.py`) is **deferred** to Phase 3: the current pipeline needs the importer's rig step and Clip Editor anyway, and `ROBLOX_OPEN_CLOUD_KEY` is verified but unused. | `docs/CHARACTER_PIPELINE.md`; 21 characters and 6 props are already live through this path. |
| D-005 | 2026-10-17 | **StyLua is advisory**, not a gate: 96 source files at HEAD are not StyLua-formatted and several Claude sessions edit this checkout at once, so whole-file reformats clobber live edits. `tools/check.*` reports the count; gates are selene, `luau-lsp analyze`, `lune run tests/run`, `rojo build`. Generated clips (`src/shared/Anim/Clips/`) are in `.styluaignore`. Format only new files. | Memory note "repo-formatting-and-shared-checkout"; measured in P0-03. |
| D-006 | 2026-10-16 | **One place.** Arenas live in the lobby server at x ≥ 3000 (6 per server, 600 studs apart); no match place, no teleports. Revisit (BUILD_PLAN P2-01) if server size or memory demands it. | `docs/TOWER_DEFENSE.md` §3, `ArenaService`. |
| D-007 | 2026-10-16 | **IP stance.** Inspired by the classic Damascus hara dramas; the owner explicitly chose to use the series' main character names and roles (COPYRIGHT_REGISTER C-201). No series title in title/tags, no actor likenesses, no theme music or recordings. | Owner's decision after the legal risk was explained; register tracks each name. |
| D-008 | 2026-10-17 | The research kit's **stat grades, evolution and 10-archetype attribute system are not adopted** now. Growth axes stay: upgrades, stars (+5 % per star, 5 stars), one trait (8 traits, Legend 0.5 %). Attribute checks are stealth (`hitsStealth`) and armor. New power axes must declare a cap here before shipping. | Keep the live economy tight (`docs/TOWER_DEFENSE.md` §5, §11); revisit in live ops when retention data exists. |
| D-009 | 2026-10-17 | Branching: work on `phase/<n>` cut from `feat/vertical-slice`; one task per commit; the owner merges and publishes. | Owner's instruction (chat, 2026-10-17). |
| D-010 | 2026-10-17 | The Hakawati's room keeps its **daily lira cap** (240 × VIP/Premium bonus) although the genre's AFK chambers are uncapped. | Our lira economy is far tighter (`docs/AFK_CHAMBER.md`); re-run the economy numbers before removing it. |
| D-011 | 2026-10-17 | TUNE-free code fix in P0-03: `RigAnimController` passed `speedMul` as `dt` to `animateEnemy` and omitted `smooth`, so imported enemies stepped their walk clip by whole seconds per frame; towers also lost `smooth`. Now near figures interpolate, far ones step at a third rate. `BoneAnim.clipsFor` narrows its cache value with `type(got) == "table"`. | Found by `luau-lsp analyze` (3 type errors at HEAD). No balance change. |
| D-012 | 2026-10-17 | **TUNE: stun chains** `TD.STUN_CHAIN_MAX` 60 → **6 s**, `TD.STUN_IMMUNITY` stays **3 s**: an enemy walks at least a third of the time under any stun pattern. 2.5–5 s caps let the wave-40 Commandant through against myth12up (endless w40, below the 60–100 target); 6–7 s is a stable plateau. Story results move by a few gate HP; endless Mythic/whale runs end 1–2 boss waves earlier; a party of 4 myth12up now loses ep1 Nightmare (w20), matching "Nightmare needs the whale". | Discord bug report "infinite stun if placing Abu Khater in a pattern" (2026-10-17). `docs/TOWER_DEFENSE.md` stun-chain note and regenerated balance tables. |

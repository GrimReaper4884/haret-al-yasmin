## 4. Six questions for the testers (post in `#game-feedback`, one message, plain English + one Arabic line)

1. On your first visit, how long did it take before you were in a match and wave 1 had started? Did anything stop you on the way (menus, not knowing where the portal is, lira)?
2. When you lost Episode 1 the first time, what did you think you should have done differently: better placement, upgrades, a different defender, or more lira for summons?
3. Which defender did you like most, and why? Which one felt useless?
4. "The UI needs an upgrade": which screen or moment exactly? (The match bar, the summon screen, the unit panel, the lobby menu, the toasts?) One screenshot helps most.
5. Did you try anything in the lane besides the portal: the coffee house, the wardrobe, the Hakawati's room, codes, the daily chest? If not, did you know they were there?
6. Would you play again this week without being asked, and what would you do first when you came back? (Yes / maybe / no, and one line why.)
